**Mafoko** consolidates South Africa's fragmented terminology resources into open, structured datasets. It uses a retrieval-augmented framework to improve translation accuracy in specialised domains {% cite marivate2025mafoko %}. Related work surveys cross-lingual embedding methods for low-resource settings {% cite SINDANE2025100157 %}.
